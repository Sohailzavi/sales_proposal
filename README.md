# iBunify Sales Proposal Builder

A lightweight React proposal editor with:

- Editable proposal details
- Add, delete, duplicate, and reorder sections
- Live document preview
- Browser autosave using localStorage
- iBunify sample proposal data
- PDF export through the browser print dialog
- Word-compatible `.doc` export
- HTML export
- JSON backup export

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## PDF export

Click **Download PDF**. In the browser print dialog, choose **Save as PDF**.

## Word export

Use **More exports → Word document (.doc)**. The downloaded file opens in Microsoft Word and most compatible editors.
